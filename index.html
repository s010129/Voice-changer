④ 接到 LINE / Discord(第一次設定)

  1. 安裝免費的虛擬音源線 VB-CABLE:到 vb-audio.com/Cable 下載,解壓縮後對 VBCABLE_Setup_x64.exe 按右鍵 →「以系統管理員身分執行」→ Install Driver,裝完重新開機。
  2. 用 Chrome 或 Edge 打開這個網頁,按「啟動變聲」並允許使用麥克風。
  3. 輸入選你的外接麥克風;輸出到通話選 CABLE Input (VB-Audio Virtual Cable)(偵測到會自動幫你選)。
  4. Discord:使用者設定 → 語音與視訊 → 輸入裝置選 CABLE Output (VB-Audio Virtual Cable)。
  5. LINE 電腦版:設定 → 通話 → 麥克風選 CABLE Output (VB-Audio Virtual Cable)。
  6. 想聽到自己變聲後的聲音:監聽選你的耳機。
不要把 CABLE Input 設成 Windows 的「預設播放裝置」,否則 YouTube、通知音等所有電腦聲音都會跑進通話裡。
  1. 安裝免費的虛擬音源線 BlackHole 2ch:到 existential.audio/blackhole 下載, 或用 Homebrew:brew install blackhole-2ch。裝完建議重新開機。
  2. 用 Chrome 打開這個網頁,按「啟動變聲」並允許麥克風(若沒跳出詢問:系統設定 → 隱私權與安全性 → 麥克風 → 打開 Chrome)。
  3. 輸入選你的外接麥克風;輸出到通話選 BlackHole 2ch。
  4. Discord:使用者設定 → 語音與視訊 → 輸入裝置選 BlackHole 2ch。
  5. LINE 電腦版:設定 → 通話 → 麥克風選 BlackHole 2ch。
  6. 想聽到自己變聲後的聲音:監聽選你的耳機。

常見問題

  • 手機版 LINE / Discord 沒辦法用:手機系統不允許別的 App 假裝成麥克風,只能在電腦版通話使用。
  • Discord 效果不見或斷斷續續:到 語音與視訊 關掉「雜訊抑制(Krisp)」和「回音消除」,它們會把機器人、回音等效果當成雜訊濾掉;輸入靈敏度建議改手動。
  • 網頁分頁要保持開著(可以縮小視窗,但不要關掉),關掉通話就沒聲音。
  • 出現尖銳嘯叫:戴耳機,不要讓喇叭的聲音被麥克風收進去。
  • 「輸入」不要選 CABLE Output / BlackHole,那樣會讓聲音自己繞圈,網頁會提醒你。
  • 聲音有爆音或卡頓:關掉其他吃 CPU 的程式;Windows 可到「聲音設定」把麥克風和 CABLE 的取樣率都設成 48000 Hz。
  • 延遲:變調大約多 30 ms,總延遲通常在 50–100 ms,講話不太會感覺到。
建議使用 Chrome / Edge 110 以上・所有聲音都在你的電腦上處理,不會上傳
